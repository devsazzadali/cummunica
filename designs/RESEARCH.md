## What makes a chat UI look premium (synthesis)

1. **One clear hierarchy per screen.** Chat list = avatar → name → preview →
   time/badge in one scan. Chat = header, messages, composer — nothing else
   competes. Premium screens remove elements; they do not add decoration.
2. **Consistent spacing system.** 8px grid, 16px screen padding, 12–14px gaps
   between rows, generous whitespace in Minimal Light, tighter but even
   spacing in WhatsApp Premium. Uneven gaps are the fastest premium-killer.
3. **Restrained colour.** One accent + neutrals wins over rainbow UIs.
   WhatsApp's green, iOS blue, and dark-mode emerald all work because the
   rest of the screen stays quiet. Gradient is used sparingly (headers,
   avatars, primary buttons), never on every surface.
4. **Typography as hierarchy, not decoration.** 17px body, 15px previews,
   12–13px metadata, 22–30px screen titles, semibold names, regular previews.
   Bengali text needs Noto Sans Bengali / Hind Siliguri at the same sizes —
   never a novelty font.
5. **Icon discipline.** One stroke width (2px), one size family (22–24px),
   Lucide-style outlined icons. Emoji as UI chrome instantly reads as
   amateur; the premium kits all use vector icons, with emoji only inside
   user message content (if at all).
6. **Bubble shape tells the story.** Own vs other must differ by colour AND
   position, with a small tail-side radius change. Large pill bubbles read
   friendly (iOS minimal); medium rounded rectangles read efficient
   (WhatsApp); soft 20px+ bubbles with depth read premium-dark.
7. **Soft, disciplined depth.** Cards with 2–12px blur shadows, 1px borders
   on light themes, glass/blur headers, and (in dark mode) layered surfaces
   instead of pure black. Heavy shadows or no separation both look cheap.
8. **Call screens are minimal by design.** One large avatar, one state line,
   one timer, four large controls (mute, speaker, video, end). Clutter on a
   call screen reads as unfinished, however good the chat list looks.
9. **Status/updates need rings, not dots.** A coloured ring around the
   avatar (solid = unseen, dashed/grey = seen) is the pattern every premium
   kit uses; a plain dot is invisible at a glance.
10. **Accessibility is part of premium.** 44px+ touch targets, 4.5:1 text
    contrast, unread badges that do not rely on colour alone (number +
    position), and online status shown by text as well as colour.

## Feature-by-feature notes (what the best examples do)

- **Chat list:** search bar always visible, filter chips (All/Unread/
  Favourites/Groups), unread badge on the right, muted/archived separated.
- **1:1 chat:** sticky bottom composer (pill input + send), voice-note
  waveform row, photo card with rounded corners, read ticks that change
  colour (grey → blue/green) rather than shape.
- **Group chat:** sender name in a distinct colour per sender above each
  incoming bubble, system messages centred in a pill ("Mim joined").
- **Calls list:** incoming / outgoing / missed distinguished by colour +
  label + icon, not colour alone; video vs audio shown by icon.
- **Call screen:** quality/connection note ("HD audio · Clear") next to
  the timer — premium calling UIs surface quality instead of hiding it.
- **Updates:** "My Status" first with a dashed add-ring, then recents;
  viewer screen shows one large status with a reply box.
- **Communities:** card per community (avatar, member count, announcement
  preview, one primary action) — not a plain list.
- **SAZMU AI chat:** clearly labelled "AI — not a human" in the header,
  suggestion chips above the composer, a distinct avatar colour.
- **Settings:** profile card on top, then grouped menu rows with icons;
  destructive action (Log out) separated and coloured red.
